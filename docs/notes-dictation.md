# Notes dictation (Sticky candidate)

**Source candidate only. Do not provision a real key until the target and device gates have passed.**

In Settings → System → Notes dictation, scan the official OpenAI key-setup QR **on your own phone**. The QR is only a link, not a pairing or login token. Create a dedicated project key, restrict its permissions to the required transcription endpoint where supported, and set usage alerts/limits in the API account. Enter it on the Sticky password keyboard; never send it to support. Setup makes no verification/billing call. The key is held for this boot only. Forget removes the app-held key; revoke it separately at OpenAI if lost. No SD settings export or unencrypted NVS secret. This does not protect an unlocked device or compromised firmware.

Open a card → Options → Dictate (OpenAI). Use Notes 0.1.5 from the normal Store install location, and choose English or Deutsch for the consent screens. Choose **Connect Wi-Fi** to open the network picker when the radio is off. Cancelling releases the picker’s radio; after a successful connection, leaving dictation releases it. An existing association is borrowed without teardown. A disconnected but active radio is left alone. App networking must be enabled. A fresh SNTP exchange is required for each upload; SNTP assumes a trustworthy network time source. Record up to five seconds locally. Stop ends capture; only **Send audio to OpenAI** starts a billable request. Back or Cancel drops the pending recording; cancellation after Send cannot retract audio or charges. No automatic retries. Only audio from this capture is sent, not the existing note. Review/edit the returned transcript: Done appends it, Back discards it. The existing Notes journal handles saving. The limit is 3072 UTF-8 bytes and 97 lines per card, including the existing note and separator. Oversized appends are refused, not truncated. Existing edits are checkpointed before recording; a failed write prevents dictation. The provider handles uploaded data under the owner's API data controls; local discard does not delete remote data.

Target and live qualification pending; see task evidence. An offline host check is `python3 test/notes_dictation/run.py` (host C/C++ compiler, vendored firmware Lua and ARDUINOJSON_INCLUDE_DIR pointing to cached ArduinoJson 7.4.2/src). No credentials needed.
