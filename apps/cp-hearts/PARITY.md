# Hearts — original CrossPlay table presentation

On Lua heaps of at least 512 KiB, the app uses the original landscape HeartsScreens geometry: 56px black header, four seat plaques, diamond trick table, passing tray, 92x122 fanned hand, legal-card dither, pass/play-on controls, four original rules pages, moon banner and hand/final score rows. Original Jersey 10/14/20/30 masks and original Noto suit cuts (18/46) are app-private and retain their licenses. Entering selects landscape; leaving restores the previous orientation. Touch targets and physical-button focus use the same control table. Opponents advance only while the table is visible; complete tricks wait for PLAY ON.

The existing rule core and game snapshot format are unchanged. This includes passing rotation, opening two of clubs, following suit, first-trick penalties, unbroken hearts, shooting the moon, and 100-point ending. Only your hand and cards already in the public trick are drawn. The simpler existing public-information heuristic remains, rather than the original HeartsBrain; the unsupported SHARP/ROOKIE toggle is replaced with a noninteractive LOCAL TABLE label. Nearby is absent.

The original menu record cells now show actual completed games, first-place finishes (including tied first place), and best place observed by this version. The separate bounded, checked two-slot `ui-record-*.dat` journal deduplicates the current completed match, verifies writes, and falls back from a torn latest slot. Earlier completed games cannot be reconstructed. Existing checked game saves, five-second action debounce, and exit save remain. New-game replacement requires a second tap and can be cancelled by RESUME. Power loss can lose recent unsaved actions. The low-memory branch is a byte-identical copy of the previous main adapter, gated before loading artwork.

Native validation: `python3 test/hearts_jaipur_graphics/run.py` uses the vendored int32/float32 Lua with 75 KiB and 2 MiB allocator limits. It covers a complete graphical match, every rules page, legal rendered targets, hidden hands, AI pause, orientation restoration, save reopening, record deduplication/torn-write recovery/failures, compact adapter lifecycle and existing independent rule fixtures. SVG captures replay actual Lua mask draw calls. Integer-rounded glyph advances and no kerning mean these are not proof of pixel-perfect physical rendering. Native allocator numbers exclude renderer/HAL allocations.

Confirm records count a completed game once and inspect Application Error/OOM logs and internal/PSRAM largest blocks. No EPUB cache reset is needed.
