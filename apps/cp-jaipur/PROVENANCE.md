# Provenance

Adapted from the owner-supplied CrossPlay checkout, revision `4d40b952f52562e3816585c98bbbaf99d269d9d1`, `src/apps_local/jaipur/`. Original MIT notice is preserved in LICENSE-CrossPlay.txt. New Lua implementations and UI are adaptations, not original engine binaries.

No external content or art bank bundled.

No restricted Picross bank, Zachtronics dungeon bank or Underhand APK assets are included.


Sticky original UI parity (2026-11-16)

UI geometry and words follow immutable CrossPlay
`d3a49ce8e85f9bd0d3e0c774a54adc267fd7547b`. Jersey glyph bytes and original card/
goods masks retain the included original MIT and font notices. Rules, AI, records,
save formats and compact UI are unchanged. Exact `legacy_*` UI copies preserve
621719e4 on unknown and nonSticky devices. New assets load only on Sticky's
existing enhanced (PSRAM-class) branch; constrained C3 remains on compact.lua.

`art/nearby32.raw` is the original Toybox nearby icon (Lucide MIT notice retained).
`art/tutorial-1.raw` through `tutorial-7.raw` are immutable original tutorial
illustrations, generated by the original JaipurScreens.cpp/JaipurArt/Jersey native
renderer and cropped at x16,y199,448x280; they are licensed source-derived art,
not substitute designs. `tutorial-dot.raw` is its exact inactive rounded dither
dot. The port renders all captions, titles, the eighth rules page and controls
live. One active illustration (15,680 bytes) is cached, avoiding repeated SD reads
and heap churn on redraw. Regeneration: test/hearts_jaipur_original_ui/tutorial_assets.py.

The existing core lacks per-seat per-good payout history, so the native six-goods
results span displays actual COMBINED GOODS totals rather than fabricated per-good
payouts. Actual bonus/camel/total/seals and the original result positions remain.
Last-move prose is derived only from a successful runtime move and its actual
before/after values; reopening a save leaves this line blank because no last move
is stored. Nearby has no backend in this Lua ABI: PLAY NEARBY opens an explicit
unavailable notice and preserves the local game, rather than inventing peers.
Jaipur remains portrait in both entry orientations and restores the host on exit.
