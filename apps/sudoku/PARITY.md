# CrossPlay parity and limits

Ported the full ten-technique ladder: naked/hidden singles, locked candidates, naked/hidden pairs/triples, X-Wing, XY-Wing and Swordfish. Grading uses the hardest deduction, not clue count. Seeded fill, rotational symmetric maximal dig at the full technique ceiling, and wrong-band rejection reproduce source puzzles. An independent MRV solver checks uniqueness; source differential tests compare completed grids, hardest technique, step counts and hints. An explicit generation job performs 128 fill probes or one removal-pair solve per update. Cancel drops the job without replacing the current puzzle; 200 rejected attempts produce a retry notice.

Four difficulty bands, a numeric keypad, immutable clues, tap-to-arm clue digits, toggle entries, raw pencil notes with peer masking, conflict markers, 24-step undo, elapsed time, wrong-entry detection and technique-labeled hints are implemented. Touch Notes mode substitutes for the source hold gesture because the delivered host emits taps only. Hints apply the proven placement immediately instead of a separate source suggestion overlay. Source per-level completed/best-time records, cached puzzle inventory, and its font/artwork are not ported. The solver and generator are substantive translations, not the old random-clue generator.

Tests use the committed Lua source with signed int32/float32 settings and only shipped host APIs. They are native adapters, not a firmware build. Read the independent test directory for exact source oracles, failure injection and measured memory. No firmware/SDK download, flash, commit, push or PR creation was performed.

CrossPlay gameplay is selected only when `smudge.get_device()` returns `"sticky"`. Every other device (including X3, X4, X4 Pro and simulator), and firmware without that API, runs the byte-identical original game from base `2c82f306`. Original modules, assets, callbacks and save APIs are preserved; the replacement core/journal is never loaded on that path.

All CrossPlay feature descriptions and limitations above apply to Sticky only. Legacy behavior (including pre-existing limitations) is intentionally unchanged elsewhere. Native adapters use the stock int32/float32 Lua configuration but host pointers and instrumentation differ from hardware. Full legacy trace comparisons use a 2 MiB host cap; separate 75 KiB observations compare the unchanged baseline and dispatcher candidate and do not claim hardware memory parity.
